# 🧮 Calculadora Java

Uma calculadora desenvolvida em Java durante meus estudos, utilizando programação orientada à lógica, estruturas de controle e programação orientada a objetos.

## 🚀 Funcionalidades

- ✅ Soma
- ✅ Subtração
- ✅ Multiplicação
- ✅ Divisão
- ✅ Potência
- ✅ Raiz quadrada
- ✅ Resto da divisão
- ✅ Histórico das operações
- ✅ Limite de 10 operações armazenadas
- ✅ Histórico numerado
- ✅ Opção para limpar o histórico
- ✅ Tratamento para divisão por zero
- ✅ Validação para raiz quadrada de números negativos
- ✅ Menu interativo em loop

## 🛠️ Tecnologias

- Java
- IntelliJ IDEA
- Git
- GitHub

## 📚 Conceitos praticados

- Estruturas de decisão (`switch` e `if/else`)
- Estruturas de repetição (`while` e `for`)
- Entrada de dados com `Scanner`
- Classe `Math`
- Formatação de saída com `printf`
- Manipulação de `String`
- Controle de fluxo
- Criação e utilização de classes
- Programação Orientada a Objetos
- Métodos
- Encapsulamento
- `List` e `ArrayList`
- Adição, remoção e acesso de elementos em listas
- Versionamento com Git e GitHub
